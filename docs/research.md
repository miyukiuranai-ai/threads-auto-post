# 競合の運用を見る（収集できるか確かめる）

「他の名義が毎日どんな時間に、どんな形で投稿しているか」を集めたい場合の手順です。

## 結論から

**今のままでは他人の投稿は取れません。** 権限が2つ足りません。しかも、その権限が開発モードのまま使えるのか、Meta の審査（App Review）が要るのかは、実際に叩いてみないと分かりません。

- `threads_keyword_search` … 公開されている投稿をキーワードで探す
- `threads_profile_discovery` … 公開アカウントのプロフィール（フォロワー数など）を見る

ですので、**作り込む前に確かめる**手順にしています。

## 1. 権限を足す

1. https://developers.facebook.com/apps → このツール用のアプリ。
2. 左メニュー「ユースケース」→ Threads の「カスタマイズ」。
3. 次の行の「追加」を押します。
   - `threads_keyword_search`
   - `threads_profile_discovery`
   - （いいね数も欲しいなら `threads_manage_insights` も）
4. 状態が「テスト準備完了」になれば、テスターの名義では試せる見込みです。「App Review が必要」と出る場合は、審査を通さない限り使えません。

## 2. トークンを取り直す

**既存のトークンには後から権限が付きません。** 1つの名義でよいので取り直してください。

シークレットウィンドウでその名義にログイン → ユーザートークン生成ツール → 生成 → コピー → 画面の「名義の管理」に貼り付け。

## 3. 何が取れるか確かめる

`threads-auto-post` フォルダでコマンドプロンプトを開き（アドレス欄に `cmd`）、

```
npm run threads:check
```

名義ごとに、次の5つを実際に叩いて結果を出します。

```
=== @mizuki_uranai_ ===
  ✓ 自分のプロフィール       @mizuki_uranai_
  ✓ 自分の投稿の一覧         5件
  ✓ いいね数（インサイト）   いいね 12 / 表示 480
  ✗ 公開投稿の検索           (#10) Application does not have permission
      threads_keyword_search を足してトークンを取り直してください（審査が要る場合あり）
  － 他人のプロフィール       --profile ユーザー名 を付けると試せます
```

試す語や相手を変えられます。

```
npm run threads:check -- --query 占い --profile mikoto_uranaishi
npm run threads:check -- --account mizuki_uranai_
```

## 4. 結果によって、できることが変わります

| 結果 | できること |
| --- | --- |
| 「公開投稿の検索」が ✓ | キーワードに当てはまる公開投稿を集められます。投稿時刻・本文・投稿者名が取れるので、どの時間帯に多いか、どんな型が多いかを見られます |
| 「他人のプロフィール」が ✓ | 相手のフォロワー数を定期的に記録して、伸びを追えます |
| どちらも ✗ | API からは集められません。人が見て書き留める形になります |

`npm run threads:check` の結果を見せてもらえれば、それに合わせた収集の仕組みを作ります。

## 気をつけること

- Threads API の外（画面を自動で読み取るなど）で集めるのは、Threads の規約に反します。このツールは公式 API だけを使う方針なので、そちらには広げません。
- 取れるのは公開されている投稿とプロフィールだけです。非公開のものは取れません。
- キーワード検索は数に上限があります（1日あたりの呼び出し回数）。集めすぎると止まるので、対象の語をしぼるのが現実的です。
