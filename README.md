# threads-auto-post

Threads の複数名義（アカウント）を、公式 Threads API だけで**一括して自動投稿**する管理画面です。
文章を数百通り貯めておき、そこから自動で投稿する仕組みに、今すぐ投稿・予約投稿（画像・動画つき）を加えたものです。

threads-ops-2 と違い、**文章を AI が考えることはなく、承認の手順もありません**。入れた文章がそのまま出ます。

## できること

| 画面 | 内容 |
| --- | --- |
| 全体状況 | 名義ごとの稼働状態、次に自動投稿が出る時刻、今日の投稿数、失敗、トークンの期限。全部まとめて稼働／停止 |
| 今すぐ投稿・予約 | 名義を複数選んで同じ内容を送る。画像（JPEG/PNG）・動画（MP4/MOV）を付けられる。日時を指定して予約もできる |
| 投稿の予定と履歴 | 予約の時刻変更・取消・本文の編集、失敗の送り直し、投稿済みの削除 |
| 文章ストック | 自動投稿に使う文章。貼り付け・ファイル（.txt / .csv）で数百本まとめて取り込む。名義ごと／全名義共通、タグ、有効／無効 |
| 自動投稿の設定 | 名義ごと（まとめても可）に「毎日 07:00, 12:30, 21:00」「2〜5時間おき（07:00〜23:00）」などを決める。文章はランダム（一巡するまで重複なし）か登録順 |
| 名義の管理 | トークンを貼り付けて名義を登録（1行に1つでまとめて）。停止／稼働、外す |

## 仕組み

- Next.js（App Router）を Vercel に置き、データは Firestore、画像・動画は Firebase Storage に置く。
- 5分おきに `/api/cron/tick` を呼ぶと、自動投稿の枠を確かめて文章ストックから投稿を作り、予定時刻を過ぎた投稿（自動・予約）を Threads へ送る。トークンの延長も 1 日 1 回ここで行う。
- 「今すぐ投稿」は画面から直接送る（定期実行を待たない）。

## よくある質問

**料金はかかる？**
文章を AI に考えさせないので、Anthropic などの AI の費用は一切かかりません。Threads API も無料です。
かかりうるのは置き場所だけで、Vercel（Hobby プラン）と Firestore は無料枠に収まります。Firebase Storage は従量課金（Blaze）プランが必要で、画像・動画の量なら月に数円〜数十円程度です。画像・動画を使わなければ Storage は不要です。

**アカウントの追加は threads-ops-2 と同じ？**
同じです。Meta for Developers のアプリで名義を「Threads テスター」に招待 → 名義側で承認 → 「ユーザートークン生成ツール」でトークンを発行 → 画面の「名義の管理」に貼り付け。
threads-ops-2 で使っている Meta のアプリをそのまま使えます（既にテスター登録済みの名義なら、トークンを発行して貼るだけ）。詳しくは docs/SETUP.md の第 6 章。
