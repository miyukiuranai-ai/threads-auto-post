# 画面の使い方（threads-auto-post）

## 全体状況
- 名義ごとに、稼働／停止、自動投稿の設定、次の自動投稿の時刻、今日の投稿数、最終投稿、文章の残り本数、トークンの残日数が出ます。
- 「稼働中」「停止中」のボタンを押すと切り替わります。右上の「全部を稼働にする」「全部を停止にする」で一括。
- **停止中**は、自動投稿と予約投稿が出ません。「今すぐ投稿」はできます。
- 「定期実行が動いていません」と赤く出たら、5 分おきに呼ぶ仕組み（docs/SETUP.md 第 10 章）が止まっています。

## 今すぐ投稿・予約
1. 名義を選ぶ（複数可。「すべて選択」「稼働中だけ」もある）。
2. 本文を書く（500 文字まで）。画像・動画は点線の枠を押して選ぶか、枠の中へドラッグして落とす。**一度に何個でも**入れられる（選ぶ画面では Ctrl を押しながらクリックで複数選択）。2 つ以上入れると複数枚の投稿になり、一覧に付く番号の順に並ぶ。順番は ↑ ↓ で入れ替えられる。画像と動画を混ぜてもよい（20 個まで）。
3. 「今すぐ投稿」か「予約する」（日本時間）を選んで送る。
- 今すぐ投稿は名義ごとに結果が出ます。動画は Threads 側の変換に数分かかるので「準備待ち」になることがあり、その場合は数分後に自動で公開されます。
- 予約は「投稿の予定と履歴」で時刻の変更・取消ができます。

## 投稿の予定と履歴
- 上の段で名義、下の段で「予約中」「投稿済み」「失敗・時刻切れ」「取消・見送り」を切り替えます。
- 予約中: 予定時刻の変更、本文の編集、取消。
- 失敗・時刻切れ: 理由が赤字で出ます。「今すぐ送り直す」でその場で再送。
- 投稿済み: 「投稿を開く」で Threads の投稿へ。「Threads から削除」で本当に消す（戻せない）。「記録を消す」はこの画面の記録だけを消す。
- 「見送り」は、直前の投稿や予約と近すぎたため自動投稿を出さなかった記録です。

## 文章ストック
- 貼り付けて取り込む: `---` だけの行で区切る（既定）。1 本の中に空行があっても大丈夫。空行で区切る／1 行 = 1 本にも変えられる。
- ファイル: .txt は同じ区切り方。.csv は 1 列目が本文、2 列目がタグ（Excel で「CSV UTF-8」で保存）。
- 使う名義: 「全名義共通」はどの名義の自動投稿にも使われる。名義を選ぶとその名義だけ。同じ文章が複数の名義から出るのを避けたいなら、名義ごとに分けて入れる。
- タグ: 取り込む全部に付く。自動投稿の設定で「このタグの文章だけ使う」と絞れる。
- 一覧: 名義・タグ・使わせる属性・有効／無効・本文検索で絞れる。「編集・添付」で本文・タグ・名義を変え、画像・動画も付けられる（その文章が自動投稿されるときに一緒に出る。複数可、順番の入れ替えも同じ）。「無効にする」と自動投稿に使われなくなる（消さずに休ませる）。
- 「絞り込んだ N 本をまとめて削除する」で、いま表示している分を一括削除（「削除」と入力して確定）。
- 1 本は 500 文字まで。長すぎるものは取り込み時に飛ばして知らせます。

## 自動投稿の設定
- 名義を選び（複数可）、設定を入れて「選んだ名義に適用する」。上の一覧の「この設定を読み込む」で、その名義の今の値をフォームに入れられる。
- **毎日決まった時刻**: 「07:00, 12:30, 21:00」のように。その時刻を過ぎた最初の定期実行（5 分おき）で出る。1 時間以上遅れたら見送り。
- **〇時間から〇時間おき**: 例「2 と 5」で、前の投稿から 2〜5 時間後（毎回ランダム）に次が出る。時間帯（例 07:00〜23:00）の外には出さず、次の開始時刻まで待つ。同じ時刻にすると終日。
- 両方 ON でもよい。どちらも OFF なら自動投稿なし（予約と今すぐ投稿はできる）。
- 文章の選び方: ランダム（一巡するまで同じ文章を出さない）か登録順。どちらも全部使い切ったら最初から。「一巡をやり直す」で使った記録を消せる。
- 使うストック: この名義用＋全名義共通／この名義用だけ／全名義共通だけ。タグで絞ることもできる。
- 直前の投稿からあける最低の分数: 予約投稿や今すぐ投稿の直後に自動投稿が重ならないようにする（既定 30 分）。重なったら「見送り」（毎日の枠）か「少し先へずらす」（間隔の枠）。

## 名義の属性（{属性} の差し込み）

同じ文章を、名義ごとに違う言い回しで出すための仕組みです。AI は使いません。ただの置き換えです。

**文章ストックは1つだけで足ります。** 名義ごとに用意する必要はありません。`{属性}` と書いた1本が、看護師の名義では「看護師です。〜」、女子大生の名義では「女子大生です。〜」として出ます。名義が何個あっても、ストックは共通の1組だけです。

属性を決めていない名義には、`{属性}` を使った文章は回りません（飛ばして、属性なしの文章だけを使います）。

**1. 名義に属性を入れる**

「名義の管理」で名義の行の「属性」を押すと、設定の欄が開きます。

**属性（人物像）** は一覧から選びます。最初から選べるのは次の8つです。

看護師 ／ 保育士 ／ 教師 ／ CA ／ 女子大生 ／ アラサー ／ おばさん ／ シンママ

一覧に無い言葉を使いたいときは「その他（自分で入力）」を選んで入力します。一度使った言葉は、次から他の名義の一覧にも出てきます。

普段はこの属性だけで足ります。文章に `{年齢}` のように属性以外の言葉を差し込みたいときだけ、「他の項目も使う（任意）」を開いて足してください（全部で20個まで）。`{ユーザー名}` はいつでも使えます。

**2. 文章に差し込む場所を書く**

文章ストックの本文に、波かっこで項目名を書きます。全角の `｛｝` でも構いません。

```
{属性}だから夜は遅くて、家には誰もいません。
一人暮らしなので、来ていいよ。
```

看護師の名義では「看護師だから夜は遅くて…」、シンママの名義では「シンママだから夜は遅くて…」として、同じ文章がそれぞれの言葉で出ます。

**3. 確かめる**

- 文章ストックの一覧では、差し込みを使っている文章に `{属性}` のような印が付きます。
- 「今すぐ投稿・予約」では、本文に差し込みがあると「名義ごとの仕上がり」が出て、送る前に各名義の文章を確かめられます。
- 「名義の管理」の属性の欄には、その名義が使う文章に出てくるのに値が空の項目が赤く出ます。

**値が空のときは投稿しません。** `{属性}` のような文字がそのまま出てしまうのを防ぐためです。自動投稿ではその回を見送り、「投稿の予定と履歴」の「取消・見送り」に理由が残ります。今すぐ投稿・予約では、その名義だけ送らずに理由を出します。

**4. 属性ごとの言い回しを増やす**

「名義の管理」の「**属性ごとの言い回し**」で、属性ごとに候補をいくつも登録できます。同じ属性の名義が何個あっても、登録は1回で済みます。

差し込む場所ごとに、候補を**1行に1つ**入れます。投稿のたびに、その中から1つが選ばれます。

```
{属性} の候補
  看護師です。
  ナースしてます
  夜勤ばっかの看護師です。
```

これで `{属性}今日誰か会ってみる？` と書いた文章が、投稿のたびに次のように変わります。

- 「看護師です。今日誰か会ってみる？」
- 「ナースしてます今日誰か会ってみる？」

候補には語尾や句点を入れても構いません。逆に、文章側に `{属性}です。` と書いて候補を `看護師` `ナース` だけにする形でも動きます。

同じ投稿の中で同じ項目を2回使った場合は、同じ言葉が入ります（1つの投稿の中で食い違いません）。

差し込む場所は `{属性}` 以外にも足せます。`{前置き}` という項目を作って「夜勤明けで」「仕事終わりで」を候補に入れれば、文章の `{前置き}` がそこから選ばれます。

候補を1つも入れなければ、`{属性}` には属性の名前（看護師 など）がそのまま入ります。

**5. 属性あり・なしの両方を出す**

同じ文言を「属性を付けた版」と「今までどおりの版」の両方で出したいときは、**複製**を作ります。

文章ストックの一覧で対象を絞り込み、「**絞り込んだ N 本の「属性つき版」をまとめて作る**」を開いて実行します。元の文章はそのまま残り、先頭（または末尾）に `{属性}` を付けた文章が新しく作られます。

```
元:  今日誰か会ってみる？              ← 残る
新:  {属性}今日誰か会ってみる？        ← 追加される
```

両方が一巡の中に入るので、順番が回るたびに「今日誰か会ってみる？」と「看護師です。今日誰か会ってみる？」が混ざって出ます。

作られた文章には既定で「属性つき」のタグが付くので、後から絞り込んだり、まとめて消したりできます。すでに差し込みが入っている文章と、付けると 500 文字に近づきすぎる文章は飛ばします。

候補には `看護師です。` のように語尾まで入れておくと、そのままつながります。

**6. 属性が合う文章だけを出す**

文章ごとに「使わせる属性」を決められます。文章ストックの「編集・添付」に **使わせる属性** の欄があり、看護師・保育士などを選べます。

- **何も選ばない**（既定）… どの名義でも使う文章。属性を問わない文言はこのままで構いません。
- **選ぶ** … その属性を付けた名義だけが使います。看護師向けの文言が、女子大生の名義から出ることはありません。

複数選べます（看護師と保育士の両方、など）。属性を決めていない名義は、属性を指定していない文章だけを使います。

すでに入れてある文章にまとめて設定するには、一覧を絞り込んでから「**絞り込んだ N 本に、使わせる属性をまとめて設定する**」を使います。本文で検索して絞り込めば、対象だけにまとめて付けられます。取り込みのときにまとめて指定することもできます。

一覧の上の「使わせる属性」で、どの文章がどの属性向けかを絞って確認できます。

## 名義の管理
- トークンを貼り付けて「名義を追加」。1 行に 1 つずつ貼ればまとめて登録できる。既にある名義ならトークンだけ入れ替わる。
- 「属性」で、その名義の人物像（看護師・シンママなど）を一覧から選ぶ。文章の `{属性}` に差し込まれる（上の章）。
- 「停止する」で自動投稿と予約投稿を止める。「外す」でツールから削除（投稿の記録とその名義用の文章も消える。Threads 側はそのまま）。
- トークンの期限は定期実行が自動で延ばす。管理者は「全名義のトークンをいま延長する」で手動でも。
- 「定期実行」の欄で最後に動いた時刻を確認できる。

## 成果を見る（いいね数）

投稿の30分後と1時間後のいいね数・表示数を、定期実行が自動で記録します。

- **全体状況** の「いいねが伸びた投稿」… 直近24時間で、いいね30以上に届いた投稿の一覧（名義・属性つき）
- **投稿の予定と履歴** の各行 … その投稿の「30分後 / 1時間後」のいいねと表示

いいね数を取るには、トークンに `threads_manage_insights` の権限が必要です。無い場合は「トークンに権限がありません」と出るので、Meta で権限を足してトークンを取り直してください。詳しくは `docs/spreadsheet.md`。

スプレッドシートに書き出す手順も `docs/spreadsheet.md` にあります。目標のいいね数（既定30）は環境変数 `LIKE_TARGET` で変えられます。

## 競合の運用を見る

他の名義がどう運用しているかを集めたい場合は、権限が2つ足りません。追加して使えるかどうかは実際に叩かないと分からないので、確かめる道具を用意しています。

```
npm run threads:check
```

名義ごとに「自分の投稿」「いいね数」「公開投稿の検索」「他人のプロフィール」が取れるかを出します。詳しくは `docs/research.md`。

## 投稿モード
- 画面左下に「本番（実際に投稿）」か「テスト（送らない）」が出る。テストは環境変数 `POSTING_MODE=dry_run`。本番は `live`（既定）。
